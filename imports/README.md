# Thư mục chứa file Excel để Import vào Nhà Thuốc Medica

Bạn có thể copy trực tiếp các file Excel xuất từ KiotViet vào thư mục này:
- File Hóa đơn bán hàng
- File Sổ quỹ (Thu/Chi)
- File Nhập hàng kho
- File Trả hàng nhập / Khách trả hàng

Sau khi copy file vào đây, bạn chỉ cần nhắn vào khung chat:
`"Hãy import dữ liệu ngày 08/11/2026 từ thư mục imports giúp tôi"`
AI sẽ tự động quét file và nạp vào hệ thống.
